# Saved-score accuracy and interpretation audit

Independent low-priority replay passed for 136 completed primary calibration conditions and 52,224 cached training/validation episode traces. No neural inference, fitting, held-out evaluation, production file changes or signals to training workers were performed. Final replay took 18.87 seconds. A preliminary replay also passed; provenance checks were then strengthened and replay repeated.

Verified freeze payload/artifact hashes, model and input-cache provenance, score NPZ and array hashes, train/validation family separation, finite nonnegative float64 scores, and JSON threshold round trips. Recomputed the 21-sample minimum for each closed 20 ms interval, first-event timing over [0,1000), timely detection in [200,1000), full-episode negative FPR, early alarms and misses independently of the production decoder. Reconstructed training-negative quantile candidates and checked every saved validation candidate assessment and frozen candidate ranking. All matched. This establishes internal consistency of the saved artifacts, not independent proof of correct upstream encoding or biological validity.

Primary results: 8/10 GRUs have 32/32 timely positive detections and 0/96 negative false alarms on reused validation; 2/10 select the silent sentinel and miss every positive. Real circuit (2 gain conditions), population-average (2), weight shuffles (60), degree rewirings (60), feature-only (1) and linear-temporal (1) all have the same perfect observed validation detection/FPR. No anatomical wiring advantage is established by these ceiling results. All 126 non-GRU conditions select 5e-324, the smallest positive float64. It survives serialization/comparison and implements a positive-versus-zero sustained-output boundary. Noise robustness and physically meaningful thresholds were not demonstrated. Maximum recorded rate-model clipping fraction was zero.

Phase 11A measures an abstract escape-initiation request in open-loop synthetic clips. It does not execute action-dependent trajectories, motor/actuator delays or collision outcomes. Phase 9 integration fixtures do not substitute for independent behavioral success evaluation. Neither actual fly escape nor general simulated avoidance can be concluded here. Validation is reused for checkpoint/rate/threshold selection and is calibration evidence only.

Recommendation: no correctness finding warrants stopping this run or changing its frozen scientific rules. Complete the registered schedule for its stated benchmark purpose if resource conditions permit. If the intended product claim is reliable closed-loop escape or a specific anatomical advantage, this run is insufficient; evaluate that separately under the existing later-phase authorization gates. Do not tune this protocol or select favorable seeds in response to current outcomes. No new study or later-phase implementation was initiated.
