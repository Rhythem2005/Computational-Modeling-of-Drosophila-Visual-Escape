## Cherry-Picking Risk Assessment

The circuit includes DNp01, DNp04, and DNp06 while excluding DNp103 (3,050 + 2,350 = 5,400 total visual syn), DNp02 (2,279 + 1,935 = 4,214), DNg40 (2,272 + 1,706 = 3,978), and DNp11 (2,078 + 1,659 = 3,737). These excluded types have substantial visual input.

**Justification for inclusion set:**
- **DNp01:** Giant Fiber — the canonical escape neuron in Drosophila. Pre-selected in Phase 0.
- **DNp04:** Highest total visual input of any DN type. Discovered in Phase 1, promoted by user.
- **DNp06:** Pre-selected in Phase 0. Lower visual input than some excluded candidates.

**Potential concern:** DNp06 (2,831 syn) has less visual input than DNp103 (5,400), DNp02 (4,214), DNg40 (3,978), and DNp11 (3,737). Its inclusion is based on Phase 0 scope selection, not on connectivity ranking. This is a legitimate project-scope decision, not cherry-picking, but future work should consider whether these excluded DNs contribute to escape behavior.
